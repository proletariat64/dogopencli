# 付款规则列表的对象边界与完整采集

Status: accepted for implementation — #55–#59
Date: 2026-09-27

延续 ADR 0002 的后续版本规则范围，按 #59 纳入同行转账、降本、重试、银存切换四项独立列表快照。每项仅用已验证的首个 1000 条请求，以总数、回显及唯一身份证明完整性；分页漂移或溢出直接失败并保留旧缓存，不猜测下一页。证据见[查询契约](../research/payment/2026-09-27-payment-rules-contract.md)。

银存切换以来源节点为行，保留适用条件、规则、比例与目标的嵌套结构。展平会改变行身份和分页含义，也会把不同规则的条件错误拼接，因此嵌套筛选必须在同一适用条件、同一规则内成立，两个目标条件必须在同一目标内成立。筛选选择整个来源节点，不裁剪其子规则。降本以组摘要为行，不声称覆盖完整历史版本。

#54 要求流量列表与真实详情一起交付；30 条详情样本中有 3 条返回不同规则身份，串行复查可复现。保留该阻塞，不注册 flow 占位命令或缩减为 list-only。该边界不能用列表摘要冒充详情来绕过，复核见[阻塞报告](../research/payment/2026-09-27-payment-flow-rule-blocker.md)。
